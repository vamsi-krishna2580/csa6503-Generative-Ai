To check whether a number is prime, we need to determine if it has any divisors other than 1 and itself.

Here's a Python program that implements this check:

```python
import math

def is_prime(number):
    """
    Checks if a given number is a prime number.

    A prime number is a natural number greater than 1 that has no positive
    divisors other than 1 and itself.

    Args:
        number (int): The integer to be checked.

    Returns:
        bool: True if the number is prime, False otherwise.
    """
    # 1. Handle edge cases:
    # Numbers less than or equal to 1 are not prime.
    if number <= 1:
        return False

    # 2. Handle the special case of 2:
    # 2 is the only even prime number.
    if number == 2:
        return True

    # 3. Handle all other even numbers:
    # Any even number greater than 2 is not prime.
    if number % 2 == 0:
        return False

    # 4. Check for divisibility by odd numbers:
    # We only need to check for divisors up to the square root of the number.
    # If a number `n` has a divisor `d` greater than `sqrt(n)`,
    # then `n/d` must be a divisor smaller than `sqrt(n)`.
    # Since we already handled even numbers, we can skip even divisors
    # and only check odd numbers starting from 3.
    # We increment `i` by 2 in the loop (3, 5, 7, ...).
    limit = int(math.sqrt(number))
    for i in range(3, limit + 1, 2):
        if number % i == 0:
            return False  # Found a divisor, so it's not prime

    # If no divisors were found, the number is prime.
    return True

# --- Main part of the program to get user input and display result ---
if __name__ == "__main__":
    while True:
        try:
            user_input = input("Enter an integer to check if it's prime (or 'q' to quit): ")
            if user_input.lower() == 'q':
                break

            num = int(user_input)

            if is_prime(num):
                print(f"{num} IS a prime number.")
            else:
                print(f"{num} IS NOT a prime number.")

        except ValueError:
            print("Invalid input. Please enter a valid integer or 'q'.")
        except Exception as e:
            print(f"An unexpected error occurred: {e}")

    print("Program exited. Goodbye!")
```

### How the code works:

1.  **`is_prime(number)` function:**
    *   **`number <= 1`**: Returns `False` immediately because prime numbers must be greater than 1.
    *   **`number == 2`**: Returns `True` because 2 is the smallest prime number.
    *   **`number % 2 == 0`**: For any other even number (i.e., `number > 2` and `number` is even), it's not prime, so it returns `False`.
    *   **`limit = int(math.sqrt(number))`**: This is an optimization. We only need to check for divisors up to the square root of the number. If a number `n` has a divisor `d` greater than `sqrt(n)`, then `n/d` would be a divisor smaller than `sqrt(n)`. So, if we haven't found a divisor up to `sqrt(n)`, we won't find one after it.
    *   **`for i in range(3, limit + 1, 2)`**: This loop iterates through odd numbers starting from 3 up to the calculated `limit`. We skip even numbers because we already handled `number % 2 == 0` (and if `number` is odd, it can't have an even divisor).
    *   **`if number % i == 0`**: If `number` is perfectly divisible by `i` (meaning `i` is a divisor), then `number` is not prime, and the function immediately returns `False`.
    *   **`return True`**: If the loop completes without finding any divisors, it means the number has no divisors other than 1 and itself, so it's prime.

2.  **Main Block (`if __name__ == "__main__":`)**
    *   This part handles user interaction.
    *   It prompts the user to enter a number.
    *   It uses a `try-except` block to handle potential `ValueError` if the user enters non-integer input.
    *   It calls the `is_prime()` function and prints the appropriate message.
    *   The loop continues until the user types 'q' to quit.

```python
def is_prime(n, divisor=2):
    if n < 2:
        return False
    if n == 2:
        return True
    if n % divisor == 0:
        return False
    if divisor * divisor > n:
        return True
    return is_prime(n, divisor + 1)
```
