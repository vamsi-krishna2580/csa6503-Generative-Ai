## Description

This project implements an **AI-Powered Report Card Comment Writer** using the **Google Gemini API**.

The application takes a student's subject scores and attendance percentage as input and uses Gemini to generate a personalized **two-sentence report-card comment**.

The program demonstrates the system with three students, including a student with failing marks. For the failing student, the generated feedback is designed to remain **constructive, supportive, and encouraging** rather than negative or insulting.

---

## Objectives

- Generate personalized report-card comments using Generative AI.
- Integrate the Google Gemini API with Python.
- Use student subject scores and attendance as input.
- Generate concise two-sentence feedback.
- Handle failing marks constructively.
- Validate student input before making an API request.
- Handle API failures, timeouts, authentication errors, and rate-limit/quota errors.
- Keep the Gemini API key secure using environment variables.
