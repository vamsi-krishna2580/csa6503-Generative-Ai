## Description

This project uses the **Google Gemini API** to generate personalized two-sentence report-card comments from a student's subject scores and attendance.

The program demonstrates three students, including a student with failing marks. The generated comment for the failing student is required to remain constructive and encouraging.

## Technologies Used

- Python
- Google Gemini API
- `google-genai`
- `python-dotenv`
